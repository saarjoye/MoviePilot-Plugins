# DC助手多源版

作者：wYw

## 功能

- 支持动态新增、编辑、删除 DockerCopilot 源，适合 PVE 多 LXC 场景。
- 支持跨源容器更新通知、自动更新、进度汇报和镜像清理。
- 支持按源选择自动备份范围，留空则备份全部启用源。
- 容器选择值使用 `source_id::container_name`，避免多个 DC 中同名容器误更新。
- 任务中心提供源概览、容器操作台、更新进度、执行摘要、最近日志、手动升级确认和批量升级确认。
- 手动或批量升级后先显示“已提交/执行中”，再根据 DockerCopilot 进度接口刷新为“成功/失败/超时”，避免把任务创建误判为更新完成。
- 镜像拉取时间较长时会按默认至少 60 次、约 10 分钟继续追踪；超过追踪窗口后会先校验一次容器状态，仍无法确认时显示“等待确认”，不作为失败统计，避免大镜像下载被误判失败。
- 通知渠道只推送“正在更新、更新成功、更新失败”三类更新执行消息；“可以更新”只记录在任务中心日志中，不再主动推送。

## 配置方式

在插件配置页按设计稿交互填写：

1. 在“基础开关”中配置启用状态、Cron 周期、通知开关、进度检查间隔和次数。
2. 在“DockerCopilot 源”区域点击“新增源”，每次新增或编辑一个 DC 源：
   - `源ID`：建议使用英文、数字、下划线，例如 `pve_lxc_01`。
   - `显示名称`：例如 `PVE-LXC-01`。
   - `服务地址`：DockerCopilot 服务地址，例如 `http://dc-lxc-01:12712`。
   - `secretKey`：DockerCopilot 环境变量中的密钥。
3. 保存后刷新插件配置页，容器选择区会按 `源名称 / 容器名` 加载可选项。
4. 在“容器选择”中分别配置更新通知、自动更新和备份源范围。

## 兼容说明

- 兼容 v1.0.0 的 `sources_text` JSON 配置，插件初始化时会自动迁移到动态源列表。
- 兼容 v1.0.1 的固定源配置，插件初始化时会自动迁移到动态 `sources` 列表。
- 兼容原单源插件的 `host` + `secretKey` 配置，迁移为默认源。
- 已保存的容器选择继续使用 `source_id::container_name`。
- 已保存的进度检查次数如果小于 60，运行时会按 60 次处理；用户设置大于 60 的值会保留。

## 安全提醒

- `secretKey`、真实 DC 地址、LXC 主机信息属于敏感配置。
- 不要把真实配置截图或日志发到公开渠道。
- 插件通知、详情页和日志不会输出 `secretKey` 明文。
- 任务中心状态接口会对源地址脱敏展示，避免在详情页暴露真实 DC 地址。

## 更新记录

- `v1.0.10`：修复旧发布包持续推送“可以更新”前置提醒的问题；更新通知任务只记录可更新状态，自动更新或手动更新完成后才推送成功或失败结果。
- `v1.0.9`：按操作精简版原型重排任务中心，改为左侧源概览联动右侧容器操作台，容器行内展示更新通知、自动更新、最近结果和手动升级入口，并新增批量升级确认流程；补充更新进度区，显示容器更新阶段、进度条和失败详情，避免任务提交被误显示为实际成功；默认至少追踪 60 次，追踪结束后补充容器状态校验，长时间拉取镜像无法确认时显示“等待确认”而不计失败；通知渠道仅保留正在更新、更新成功、更新失败三类更新执行消息。
- `v1.0.8`：增强任务中心，新增“可自动升级”统计、按源过滤任务/容器、更新日志表、手动升级按钮与确认弹窗，并优化日志字段为 `source/container/image/reason`。
- `v1.0.3`：修复新增源后配置页内容被弹窗裁切，无法下拉继续设置的问题。
- `v1.0.2`：改为 Vue 远程配置页，实现“点击新增源”后在页面中添加 1 个 DC 源设置，移除固定 5 个源限制。
- `v1.0.1`：按设计稿重构配置页交互，新增多源配置、分区容器选择和详情页仪表盘。
- `v1.0.0`：新增多 DockerCopilot 源配置，容器选择使用 `source_id::container_name` 防同名冲突。
